# stream-highlights – Downloads

Hier liegt die fertige `stream-highlights.exe` zum Herunterladen:
**[Neueste Version](https://github.com/Quasiich/stream-highlights-releases/releases/latest)**

Die .exe in einen eigenen Ordner legen und doppelklicken, es öffnet sich die
Oberfläche im Browser. Ab Version 1.2.3 prüft das Programm hier auf Updates
und kann sich per **Jetzt aktualisieren** selbst auf den neuesten Stand
bringen.
